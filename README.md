## Various J2ME mappings in Enigma format
Most of these games are interesting to me, but only some other games by the same devs have unobfuscated versions. These mappings were made by me using Recaf.
- Diamond Rush (Sony Ericsson S700 version 1.2.0) remapped from Platinum Solitaire (Sagem) - only 1 engine class matches but it's still a huge find
- WALL-E (Sony Ericsson 240x320) remapped from Star Wars: Cantina (LG) - 2 classes match (one of the matches is large)
- Bounce Tales (Nokia 7210 Supernova) remapped from Burnout (BlackBerry) - only 3 engine classes match
- Ratatouille: Cheese Rush (Sony Ericsson K800i) remapped from Star Wars: Cantina (LG) - 3 classes match (one of the matches is large)
- Sonic the Hedgehog Part One (Nokia s60v3 / 6280) remapped from the demo version of the same game (Sony Ericsson W200i) - for the purpose of modding the former version
- The Legend of Spyro: The Eternal Night (Sony Ericsson K800i) remapped from Battleship and Connect 4 (BlackBerry) - 4 small engine classes match
